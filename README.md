# 🌐 Personal Portfolio

A responsive personal portfolio website showcasing my education, projects, skills, certifications, achievements, and internship experience.

- Responsive Design
- Dark/Light Theme Toggle
- Animated Background
- About Me
- Education
- Experience
- Projects
- Skills
- Certifications
- Achievements
- Contact Section
- Resume Download
